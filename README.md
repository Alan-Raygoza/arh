Alan Raygoza Hatchett — Portafolio de Análisis de Datos
Ingeniero Aeroespacial en transición hacia el análisis de datos financieros y de operaciones. Este repositorio reúne los proyectos de análisis que he construido durante mi formación como analista de datos: limpieza y modelado de datos reales, pruebas estadísticas, dashboards y recomendaciones de negocio traducidas de números a decisiones.

Cada carpeta tiene su propio README con el contexto de negocio, la metodología, los hallazgos con sus números reales, las recomendaciones y las limitaciones del análisis — pensado para poder leerse en un par de minutos sin necesidad de abrir el notebook.
Stack técnico
Análisis y datos: SQL (SQL Server, PostgreSQL), Python (pandas, numpy, scipy, statsmodels), Excel avanzado, Google Sheets
Visualización: Tableau, seaborn, matplotlib
Automatización: Make, Notion
Sobre mí
Antes de análisis de datos, pasé más de tres años como Coordinador Administrativo en casas de cambio en Tijuana — supervisando cajeros, cortes de caja, conciliación y operaciones FX en un entorno financiero regulado. Esa base es la que trato de traer a cada proyecto de este repositorio: no solo saber correr una prueba estadística, sino entender qué representa el número en la operación real del negocio antes de interpretarlo.
