## 🧭 Sobre mí

Antes de análisis de datos, pasé más de tres años como Coordinador Administrativo en casas de cambio en Tijuana — supervisando cajeros, cortes de caja, conciliación y operaciones FX en un entorno financiero regulado. Esa base es la que trato de traer a cada proyecto de este repositorio: no solo saber correr una prueba estadística, sino entender qué representa el número en la operación real del negocio antes de interpretarlo.

Este repositorio reúne los proyectos que he construido durante mi formación como analista de datos: limpieza y modelado de datos reales, pruebas estadísticas, dashboards y recomendaciones de negocio traducidas de números a decisiones.
